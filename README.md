# Borrower Copilot

A personal loan decision assistant for Indian borrowers. Understand your borrowing position before talking to a lender.

## Features

- ✅ Adaptive questionnaire based on income type (Salaried/Self-employed/Informal)
- ✅ Safe affordability calculation (what you can actually afford)
- ✅ Lender eligibility estimate (what banks might approve)
- ✅ Fair interest rate range (not a single number)
- ✅ All-in annualized cost with processing fees
- ✅ EMI recommendation with stress testing
- ✅ Tenure trade-off comparison (3, 4, 5 years)
- ✅ Negotiation Card for lender conversations
- ✅ Demo profiles (Priya, Ravi, Anita)
- ✅ Mobile responsive
- ✅ Print-ready Negotiation Card

## Tech Stack

- React 18
- Vite
- Vanilla CSS
